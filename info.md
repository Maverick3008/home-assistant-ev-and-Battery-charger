EV and Battery Charger calculates charging duration, planned charge start and planned charge end for an EV, plug-in hybrid or battery storage system. It supports a daily ready time and optional calendar-based charging. In version 1.4.1, a selected calendar event raises the target state of charge to 100% only when the event starts tomorrow and today's configured daily ready-by time has already been reached. This prevents the current morning's normal charge from being raised to 100% one night too early. Events two or more days away do not trigger 100% yet. Once activated, the same event keeps 100% across midnight until its associated charge cycle completes, after which the target resets to 80%. The selected calendar entity is refreshed every 30 minutes using homeassistant.update_entity.
