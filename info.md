EV and Battery Charger calculates charging duration, planned charge start and planned charge end for an EV, plug-in hybrid or battery storage system. Version 1.5.0 supports selecting multiple Home Assistant calendars and uses the earliest future event across all selected calendars. All selected calendar entities are refreshed every 30 minutes using homeassistant.update_entity. Existing single-calendar configurations remain compatible. The version 1.4.1 target-SOC behavior is preserved: an eligible event tomorrow may raise the target to 100% only after today's configured daily ready time has been reached, and the target resets to 80% after the associated charge cycle completes.
