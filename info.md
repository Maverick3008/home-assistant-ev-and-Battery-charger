EV and Battery Charger calculates charging duration, planned charge start and planned charge end for an EV, plug-in hybrid or battery storage system. Version 1.5.1 supports multiple Home Assistant calendars and adds a simple 03:00 fallback: if a future calendar event still exists today but the normal plan reports not_needed, the integration exposes a charging_window from 03:00 until the event regardless of SOC. This helps wallbox automations start charging when the vehicle SOC is stale or incorrect. All selected calendar entities are refreshed every 30 minutes.
